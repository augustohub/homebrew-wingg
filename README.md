# Homebrew tap for Wingg

Wingg puts two bars of widget tiles beside the macOS Dock. It is free while it is in beta.

```
brew install --cask augustohub/wingg/wingg
```

Wingg updates itself (Sparkle), so `brew upgrade` is not needed. The builds live in [wingg-releases](https://github.com/augustohub/wingg-releases). Needs macOS 14 or later on Apple silicon.
